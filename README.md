# SCT_WD_4 - To-Do Web App

## 📋 Task Overview
**Task 4** of SkillCraft Technology Web Development Internship.

Develop a basic to-do app that enables users to add and maintain tasks with full CRUD functionality.

## 🎯 Objectives
- Allow users to add new tasks to a list
- Mark tasks as completed/incomplete
- Edit existing tasks
- Delete tasks from the list
- Set due date & time for tasks
- Persist data using Local Storage
- Fully responsive design

## 🛠️ Tech Stack
- **HTML5** - Structure and layout
- **CSS3** - Styling, Flexbox, responsive design
- **JavaScript** - DOM manipulation, Local Storage, CRUD operations

## ✨ Features
- **Add Task**: Create new tasks with title + due date/time
- **Mark Complete**: Toggle tasks with checkbox + strikethrough effect
- **Edit Task**: Update task name and due date inline
- **Delete Task**: Remove tasks with confirmation
- **Date & Time**: Set deadlines for each task
- **Local Storage**: Tasks persist after page reload
- **Responsive UI**: Works on desktop, tablet, and mobile
- **Task Counter**: Shows pending vs completed tasks
